# Steering Vector Research Project

Experiments measuring how difference-in-means (DIM) steering vectors affect LLM behavior across layers, using single-token (MCF) and continuation (CF) scoring.

---

## What Is This?

We steer a language model's internal representations at inference time — no fine-tuning required. A steering vector is computed by capturing activations on two contrasting sets of prompts (positive vs. negative), taking their mean difference, and injecting that direction at a target layer during evaluation.

We test how this affects accuracy on domain-specific multiple-choice benchmarks across a range of layers and steering coefficients.

## Key Concepts

**MCF (Multiple Choice Format)** — the model is scored on the log-probability of each answer label token (A/B/C/D). The label with the highest score wins.

**CF (Continuation Format)** — the model is scored on the log-probability of the full answer text. Supports several normalisation variants (sum, mean, character-normalised, PMI).

**DIM steering vector** — computed as `mean(positive activations) - mean(negative activations)` at a given layer, then applied as `h' = h + coef * v` during forward passes.

**Coefficient** — controls the strength and direction of steering. `0` = no steering (baseline). Positive = toward the positive class. Negative = away from it.
